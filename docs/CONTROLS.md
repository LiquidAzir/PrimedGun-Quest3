# Controls

These controls describe the default **right-handed** setup with both Touch controllers. Changing handedness or swapping movement sticks changes the corresponding mappings. The game may display GameCube button icons rather than Quest button names.

## First-person gameplay

| Action | Quest control |
| --- | --- |
| Move forward/backward and strafe | Left stick |
| Turn | Right stick left/right |
| Jump | Push right stick up; return to center before another jump |
| Aim cannon | Move the right controller |
| Fire | Right trigger |
| Charge shot | Hold right trigger, then release, once unlocked |
| Lock on / grapple | Aim toward the target and hold left trigger; grapple requires the upgrade |
| Missile / beam combo | Right grip; hold a charge first for an available beam combo |
| Morph / unmorph | X, once available |
| Map | Left grip |
| Pause / inventory | Y |
| Beam selection | Hold B, aim toward the beam on the panel, then release B |

The beam panel uses **up: Power**, **right: Wave**, **down: Ice**, and **left: Plasma**. Only acquired beams can be equipped. Turning and jumping are suppressed while selecting a beam.

New Quest profiles use **headset-relative movement**: the left stick follows your horizontal head direction. Aiming stays controller-relative. To change this, open VR settings, select **Movement → Move Direction → HMD / Controller**, then select **Save**. Existing saved preferences are retained.

Lock-on uses the game's orbit behavior. Morph-ball movement uses the game's third-person controls rather than first-person headset-relative strafing.

## Visors and scanning

Raise your **left controller beside your head**, roughly at eye level and within arm's reach of the headset. While holding it there, push the left stick:

| Stick direction | Visor |
| --- | --- |
| Left | Scan |
| Up | Combat |
| Down | Thermal, once acquired |
| Right | X-ray, once acquired |

Lower your hand afterward to restore normal movement. If the gesture does not register, bring the controller closer to the side of the headset at eye level, keeping it tracked.

To scan, equip the **Scan Visor**, look toward a scan target, and hold the **left trigger** until the scan completes. When the scan text displays a GameCube **A** prompt, tap the **right trigger** to advance it; this is the first-person mapping for GameCube A. Release the left trigger before choosing another target. Raise the left controller and push its stick **up** to return to Combat Visor; firing outside an active scan also returns to combat.

## Morph ball and game menus

The game uses its classic button mapping in morph ball and menus, so some controls differ from first-person play:

| Action | Quest control |
| --- | --- |
| Move morph ball / navigate menus | Left stick |
| Bomb | A, once acquired |
| Boost ball | Hold and release B, once acquired |
| Spider ball | Hold right trigger, once acquired |
| Power bomb | Right grip, once acquired and with ammunition |
| Unmorph | X |
| Confirm / advance text | A |
| Back | B |
| Pause / resume | Y |

## VR settings, recenter, and exit

| Action | Control |
| --- | --- |
| Open or close PrimedGun settings | Left menu button or click left stick |
| Choose a tab, option, value, or Save | Aim the right-controller laser and press A |
| Recenter forward direction, position, and height | Face forward, lower the left hand, and click right stick |
| System recenter | Quest's normal system recenter action |
| Stop emulation and return to launcher | Hold left menu button + right-stick click for two seconds |

Recenter works in title screens as well as gameplay. Lowering the left hand avoids the visor gesture taking priority. Select **Save** in the VR menu to retain preference changes; changing a value alone is not a persistent save.

The VR menu's **Save** stores settings, not game progress. Save progress at an in-game save station or ship prompt before quitting.
